# 个人实践路线

当前仓库先保留课程原始工程，并用板级文档说明接口和资源关系。个人实践将在真实修改发生后逐步加入，不复制一份相同代码充当 `practice/`。

```text
course/
原始课程工程与板级接口基线
        ↓
practice/
针对已确认问题的个人实现
        ↓
integrated application
统一资源分配下的多外设应用
```

## 第一组 practice

优先处理已经能从源码确认的问题：

1. DS1302：修正写保护寄存器地址，把首次校时与正常启动分开；
2. UART：接收 ISR 只写入缓冲区，解析和发送移到主循环；
3. AT24C02：增加 ACK 检查、写完成轮询、超时和错误返回；
4. 按键：用周期扫描和边沿事件替代等待释放；
5. 显示：使用 Timer0 固定刷新数码管或点阵，应用层只更新缓冲区。

每个个人版本与对应 `course/` 并列保存，并在 README 中记录修改原因、接口变化和验证方式。

## 综合应用方向

个人驱动稳定后，再组合一个板级状态终端：

```text
Keys / ADC / RTC
        ↓
Application state
        ↓
Seven-segment or LCD
        ↓
AT24C02 configuration
```

开始编码前先建立 GPIO、Timer 和中断资源表，解决 P0、P2、P3.4~P3.7 的复用冲突。只有完成编译或实机验证后，运行记录才会进入 `assets/images/runtime/`。
