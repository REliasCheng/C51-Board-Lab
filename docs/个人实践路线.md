# 实践扩展设计

各项目的 `course/` 目录提供板级接口与现有实现基线。独立实现只有在接口变化和验证记录明确时才进入 `practice/`。

```text
course/
参考工程与板级接口基线
        ↓
practice/
针对已确认问题的独立实现
        ↓
integrated application
统一资源分配下的多外设应用
```

## 候选 practice

源码中可以定位到以下改进点：

1. DS1302：修正写保护寄存器地址，把首次校时与正常启动分开；
2. UART：接收 ISR 只写入缓冲区，解析和发送移到主循环；
3. AT24C02：增加 ACK 检查、写完成轮询、超时和错误返回；
4. 按键：用周期扫描和边沿事件替代等待释放；
5. 显示：使用 Timer0 固定刷新数码管或点阵，应用层只更新缓冲区。

对应实现进入 `practice/` 时，与 `course/` 并列保存，并在 README 中记录修改原因、接口变化和验证方式。

## 综合应用结构

板级状态终端可按以下数据流组织：

```text
Keys / ADC / RTC
        ↓
Application state
        ↓
Seven-segment or LCD
        ↓
AT24C02 configuration
```

集成前先建立 GPIO、Timer 和中断资源表，解决 P0、P2、P3.4~P3.7 的复用冲突。运行记录应与实际编译或板端验证结果对应。
