# MCU 资源分配

## GPIO

| 端口 | 主要用途 | 复用风险 |
| --- | --- | --- |
| P0 | 数码管段码、LCD 数据、点阵数据 | 同一时刻只能按当前硬件模式输出 |
| P1 | 4×4 矩阵键盘、部分电机控制 | 键盘扫描会改变高低半字节方向/电平 |
| P2.0/P2.1 | LED、AT24C02 SDA/SCL | EEPROM 通信期间不应同时刷新对应 LED |
| P2.2~P2.4 | LED、74HC138 地址 | 位选时会改变 LED 对应端口状态 |
| P2.5~P2.7 | LED、LCD 控制、蜂鸣器 | LCD 与蜂鸣器存在直接冲突 |
| P3.0/P3.1 | 独立按键、UART RXD/TXD | 串口工作时不能按普通按键口处理 |
| P3.2 | 独立按键、INT0、红外输入 | 外部中断与按键读取需要选择用途 |
| P3.3 | 独立按键、INT1 | 中断资源复用 |
| P3.4~P3.6 | 74HC595、DS1302、XPT2046 | 三类串行外设共享引脚 |
| P3.7 | XPT2046 DOUT、DS18B20 | 采样与单总线不能同时使用 |

## 定时器与中断

- Timer0：1 ms 周期示例、100 μs 软件 PWM；
- Timer1：UART 波特率发生器；
- INT0：红外输入基础例程；
- UART interrupt 4：串口接收例程。

单模块工程中资源分配是固定的。组合项目若同时使用 UART、PWM、显示扫描和按键，需要建立定时器分配表，并避免在 ISR 内执行等待发送或长延时。

## 串口参数

UART 工程在 11.0592 MHz 下使用 Timer1 模式 2，目标波特率为 9600。Keil 工程 XML 中的仿真时钟字段不参与板端定时，下载前应以实际晶振和生成参数复核。
