# 调试记录

## 数码管无显示

**现象**：代码执行，但数码管不亮。
**原因**：J24 位于点阵侧，数码管没有接入共享显示资源。
**处理**：将 J24 调到数码管侧，再检查 P0 段码和 P2.2~P2.4 位选。

## 工程时钟信息不一致

**现象**：Keil 工程 XML 中记录 24 MHz，而源码延时、Timer0 和 UART 注释均为 11.0592 MHz。
**处理**：以实际晶振和源码参数为准，重新核对定时器重装值和串口波特率，不把 IDE 仿真字段当成硬件事实。

## RTC 每次启动回到固定时间

**原因**：现有示例在启动流程调用 `SetTime()`。
**处理方向**：`practice/` 版本把一次性校时与正常读取分开，并复核 DS1302 写保护寄存器地址。

## UART 中断处理时间过长

**原因**：接收 ISR 中直接调用等待 `TI` 的发送函数。
**处理方向**：ISR 只保存字节和状态，主循环负责解析与发送。

## EEPROM 写入可靠性

**原因**：现有示例主要依靠固定延时等待写周期，ACK 失败未向上层返回。
**处理方向**：个人驱动增加 ACK 检查、超时和写完成轮询。
