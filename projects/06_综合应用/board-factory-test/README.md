# 开发板综合测试

## 功能介绍

综合测试工程通过矩阵键盘选择板载功能，覆盖 LED、数码管、点阵、XPT2046、DS1302、DS18B20、LCD1602、LCD12864、PWM/DAC 路径、蜂鸣器和 AT24C02。

该项目包含开发板出厂测试的源码、头文件和 `.uvproj`，用于检查板载外设接口与 BSP 调用关系。

## 硬件结构

```text
Matrix keys
    ↓
user/main.c
    ↓
bsp_config + device drivers
    ├─ LEDs / seven-segment / 74HC595
    ├─ XPT2046 / PWM
    ├─ DS1302 / DS18B20 / AT24C02
    └─ LCD1602 / LCD12864 / buzzer
```

## 软件结构

- `user/main.c`：键值状态、功能选择和各演示流程；
- `user/config.h`：公共类型与配置入口；
- `bsp/bsp_config.*`：板级初始化和延时；
- `bsp/<device>/`：外设驱动；
- `user/stc89c52rc_it.*`：中断文件入口。

## 关键代码

`key_updata()` 根据前后两次扫描值产生按下、释放、保持和错误状态；主循环在按下事件中选择对应演示。点阵和数码管通过缓冲区刷新，ADC、RTC 与温度结果转换后写入显示缓冲。

## 调试记录

- 多个演示函数内部使用阻塞循环，进入功能后要等待该流程结束；
- 程序启动时固定向 AT24C02 地址 0 写入 `8`，不是通用配置保存策略；
- P0、P2 和 P3.4~P3.7 被多个 BSP 模块共享，切换功能前需要恢复端口状态；
- 原文件使用旧式本地编码，仓库按原字节保存，没有改写注释编码。

## 设计说明

综合工程比单模块示例多一层板级组织：应用代码通过 BSP 驱动访问外设，并用键值状态选择功能。端口共享和阻塞流程是系统整合时需要重点处理的约束。
