# 8×8 LED 点阵

## 功能介绍

三个版本依次完成 74HC595 字节移位、静态图案和缓冲区动态扫描。

## 硬件结构

```text
P3.4 SER  ─┐
P3.6 SCK  ─┼─> 74HC595 ──> column latch
P3.5 RCK  ─┘
P0 ──────────────────────> row data
```

![点阵连接](../../../assets/images/diagram/led-matrix-wiring.png)

## 软件结构

`MxLED.c` 保存 8 字节显示缓冲区，`Write_74HC595()` 串行发送列数据，扫描函数按行更新 P0 与锁存输出。

## 关键代码

74HC595 每次接收一位数据，经 8 次移位形成一个字节，RCK 上升沿再把移位寄存器内容送到输出锁存器。动态版本逐行刷新，实现稳定图案。

## 调试记录

点阵和数码管通过 J24 共享显示资源；P3.4~P3.6 还连接 DS1302 和 XPT2046。综合运行时需要避免多个驱动同时切换这些引脚。

## 设计说明

该项目结合串行扩展、输出锁存和周期扫描，完成 GPIO 扩展与显示刷新。
