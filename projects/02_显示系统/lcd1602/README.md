# LCD1602

## 功能介绍

驱动提供命令、数据、字符、字符串和多种数字格式显示接口；案例在第二行持续显示计数值。

## 硬件结构

```text
P0 ──────────> LCD1602 D0~D7
P2.6 ────────> RS
P2.5 ────────> RW
P2.7 ────────> EN
```

## 软件结构

`main.c` 负责初始化和业务数据，`LCD1602.c` 负责总线时序与格式化显示，`Delay.c` 提供固定等待。

## 关键代码

- `LCD_WriteCommand()` 和 `LCD_WriteData()` 区分命令与显示数据；
- `LCD_SetCursor()` 根据行列计算 DDRAM 地址；
- `LCD_ShowNum()`、`LCD_ShowSignedNum()`、`LCD_ShowHexNum()` 等函数在驱动层完成格式转换。

## 调试记录

LCD1602 与蜂鸣器共享 P2.5，与数码管/点阵共享 P0。显示无字符时需要同时检查对比度、控制线和端口复用状态。

## 设计说明

LCD1602 工程将并行总线时序封装为显示 API，并分离命令、数据和字符串输出接口。
