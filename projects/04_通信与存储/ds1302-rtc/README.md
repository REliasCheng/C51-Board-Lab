# DS1302 RTC

## 功能介绍

基础版本实现 DS1302 字节读写；显示版本增加时间数组、BCD 转换和 LCD1602 时间显示。

## 硬件结构

```text
P3.6 ──> SCLK
P3.4 <─> I/O
P3.5 ──> CE
         DS1302 + 32.768 kHz crystal
```

![DS1302 接口](../../../assets/images/ds1302-interface.png)

## 软件结构

`ds1302.c` 负责三线时序、寄存器和时间数组，`LCD1602.c` 负责输出，`main.c` 完成初始化、读取和显示。

## 关键代码

DS1302 命令和数据按低位在前传输。应用层把十进制时间转换成 BCD 写入寄存器，读取后再拆分十位和个位。

## 调试记录

- 第二版 `DS1302_WP` 定义为 `0x8`，与完整写保护命令地址不一致，需要在个人版本中依据手册复核；
- `main()` 启动时调用 `SetTime()`，会覆盖芯片原有时间；
- P3.4~P3.6 与 74HC595、XPT2046 共用。

## 技术总结

RTC 工程连接了串行时序、寄存器地址、BCD 编码和应用层显示，也暴露了初始化策略对持久时间的影响。
