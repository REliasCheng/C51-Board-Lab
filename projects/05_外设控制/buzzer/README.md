# 蜂鸣器

## 功能介绍

软件延时周期性翻转 P2.5，向板载蜂鸣器输出方波。

## 硬件结构

```text
P2.5 ──> buzzer driver ──> buzzer
```

## 软件结构

`main.c` 包含端口定义、250 μs 延时和连续翻转循环，没有独立驱动模块。

## 关键代码

输出脚每隔固定时间翻转一次，一个完整声波周期由两次翻转组成。改变延时会改变音调。

## 调试记录

P2.5 同时是 LCD1602 的 RW 控制线。蜂鸣器与 LCD 同时使用时不能沿用两个单模块程序的端口定义，需要统一硬件模式。

## 技术总结

该工程给出了软件方波的最小实现，也直接暴露了板级端口复用对组合设计的限制。
