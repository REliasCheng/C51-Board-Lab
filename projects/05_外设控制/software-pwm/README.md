# 软件 PWM

## 功能介绍

Timer0 每 100 μs 进入一次中断，计数值与占空比比较后输出高低电平。两个版本分别驱动 LED 亮度和直流电机。

## 硬件结构

```text
11.0592 MHz ──> Timer0 ──> software counter
                              ├─> P2.0/P2.1 LED
                              └─> P1.0 motor control
```

电机负载通过板上驱动电路连接，MCU 只输出控制信号。

## 软件结构

`Timer0_Init()` 建立固定时间片，ISR 更新 PWM 计数并比较 `Compare`，主循环读取按键并调整占空比。

## 关键代码

一个 PWM 周期被划分为固定数量的 100 μs 时间片。当计数小于比较值时输出有效电平，其余时间输出无效电平。

## 调试记录

软件 PWM 的频率和分辨率由中断周期与计数上限共同决定。ISR 过重会产生抖动；与其他 Timer0 项目组合时必须重新分配时间基准。

## 技术总结

项目用单一定时器构造可调占空比输出，说明了周期、分辨率和中断负载之间的关系。
