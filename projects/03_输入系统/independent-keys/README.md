# 独立按键

## 功能介绍

四个版本覆盖直接读取、按键翻转 LED、按键移动 LED，以及返回键值的 `Key_Scan()` 模块。

## 硬件结构

```text
K1 ──> P3.1
K2 ──> P3.0
K3 ──> P3.2
K4 ──> P3.3
```

按键按下后改变对应输入电平。P3.0/P3.1 同时承担 UART，P3.2/P3.3 也是外部中断输入。

## 软件结构

早期版本直接在 `main.c` 判断端口；模块版由 `key.c` 完成消抖和键值映射，`main.c` 根据返回值更新 LED。

## 关键代码

现有实现采用“检测按下 → 延时消抖 → 再次确认 → 等待释放”的阻塞流程。多任务系统可改为周期采样和状态变化事件。

## 调试记录

启用 UART 后，P3.0/P3.1 不再适合作普通按键输入。按键读值异常时应先检查端口当前是否被串口或外部中断占用。

## 技术总结

四个版本将输入代码从内联判断逐步拆分为可复用键值接口。
