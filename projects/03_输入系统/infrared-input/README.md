# 红外输入与外部中断

## 功能介绍

当前工程配置 INT0，在检测到外部下降沿后翻转 LED，实现外部中断输入链路。NEC 地址、命令和重复帧解码不在该工程范围内。

## 硬件结构

```text
IR receiver ──> P3.2 / INT0 ──> interrupt 0 ──> P2.0 LED
```

## 软件结构

`main.c` 完成 IT0、EX0、EA 初始化；`Int0_Routine()` 是唯一中断处理函数。

## 关键代码

IT0 选择边沿触发，EX0 打开外部中断 0。中断发生后 ISR 只翻转 P2.0，用于确认输入路径。

## 调试记录

当前代码处理红外接收头的数字边沿和 INT0 事件，并用 LED 翻转表示中断触发。NEC 解码属于独立的协议层扩展，需要补充时序阈值和帧解析。

## 设计说明

该工程提供外部中断的最小板级验证点，并明确了从边沿检测到协议解析之间仍缺少的状态机。
