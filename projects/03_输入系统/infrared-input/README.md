# 红外输入与外部中断

## 功能介绍

当前课程工程配置 INT0，在检测到外部下降沿后翻转 LED。目录名称包含“红外遥控”，但源码没有实现 NEC 地址、命令或重复帧解码。

## 硬件结构

```text
IR receiver ──> P3.2 / INT0 ──> interrupt 0 ──> P2.0 LED
```

## 软件结构

`main.c` 完成 IT0、EX0、EA 初始化；`Int0_Routine()` 是唯一中断处理函数。

## 关键代码

IT0 选择边沿触发，EX0 打开外部中断 0。中断发生后 ISR 只翻转 P2.0，用于确认输入路径。

## 调试记录

项目只能验证红外接收头的数字边沿和 INT0，不应把 LED 翻转描述成完整红外协议通信。若后续加入 NEC 解码，应建立独立 `practice/` 并记录时序阈值。

## 技术总结

该工程提供外部中断的最小板级验证点，并明确了从边沿检测到协议解析之间仍缺少的状态机。
