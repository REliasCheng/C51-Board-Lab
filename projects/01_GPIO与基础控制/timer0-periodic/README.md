# Timer0 周期中断

## 功能介绍

Timer0 以模式 1 运行，每 1 ms 进入一次中断。ISR 累加计数，主循环根据计数切换 LED。

## 硬件结构

```text
11.0592 MHz clock ──> Timer0 ──> interrupt 1 ──> P2.0 LED
```

## 软件结构

`main()` 调用 `Timer0_Init()` 后等待计数条件；`Timer0_Rountine()` 在中断中重装 TH0/TL0 并更新计数。

## 关键代码

- `TMOD` 选择 16 位定时模式；
- TH0/TL0 保存 1 ms 重装值；
- `ET0` 和 `EA` 打开 Timer0 与总中断；
- ISR 只完成重装和计数，输出逻辑留在主循环。

## 调试记录

工程 XML 保存的仿真时钟与源码注释不一致。定时结果必须按板上 11.0592 MHz 晶振重新核对，不能只看 Keil 目标配置。

## 技术总结

该工程把软件延时替换为周期时间基准，是按键扫描、显示刷新和任务调度的起点。
