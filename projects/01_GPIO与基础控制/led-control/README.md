# LED 控制

## 功能介绍

三个版本依次实现 P2 直接输出、软件延时闪烁和位移流水灯，形成从寄存器写入到简单状态变化的最小代码路径。

## 硬件结构

```text
MCU P2.0~P2.7 ──> LED bank
```

LED 由低电平点亮。P2 还连接数码管位选、I²C 和 LCD 控制等资源，组合使用前需要查看 [MCU 资源分配](../../../docs/MCU资源分配.md)。

## 软件结构

- `01_direct-output/main.c`：直接写 P2；
- `02_blink/main.c`：软件延时后翻转输出；
- `03_running-light/main.c`：通过移位生成流水效果。

## 关键代码

流水灯把单个位图左移或右移后写入 P2。代码短，但已经包含“状态变量 → 端口映射 → 硬件输出”的基本结构。

## 调试记录

LED 与 P2 的其他板载功能共享端口。程序同时启用数码管或 EEPROM 时，LED 状态会随总线操作变化，排查时需要同时检查端口复用状态。

## 设计说明

该项目建立板卡上最直接的 GPIO 输出路径，为后续位选、总线和定时输出提供基准。
